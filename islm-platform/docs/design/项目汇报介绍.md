# IS-LM 交互式仿真学习平台 —— 项目汇报介绍

> 面向老师当面汇报使用 · 建议配合现场演示（演示动线见文末）

---

## 一、30 秒开场（一句话介绍）

这是一个面向宏观经济学课程的**辅助学习系统**：以 IS-LM 模型为核心，把「知识点学习 → 交互仿真实验 → 课后习题 → 智能导学」串成闭环。本次重点汇报新完成的 **基于 RAG 与思维链（CoT）的 AI 阶梯导学功能**——它能在学生做题卡壳时逐级引导思考，而不是直接给答案。

---

## 二、项目背景与要解决的问题

| 痛点 | 本项目的应对 |
|---|---|
| IS-LM 模型抽象，公式与曲线联动难以凭空想象 | 参数可调的**交互仿真器**，实时看到两条曲线如何移动、均衡如何变化 |
| 做题不会做时，直接看解析 → 抄答案、没有思考过程 | **4 级阶梯提示**：先给方向、再给条件、再给框架，最后一步留白让学生自己完成 |
| 通用大模型（如直接问 ChatGPT/豆包）会直接吐答案，且可能编造教材里没有的内容 | **RAG 检索限定知识库** + **防泄露校验**：答案数值根本不进入 L1~L3 的模型上下文 |
| 刷题记录、错题、学习安排分散 | 错题本、课程表、学习统计等模块统一管理 |

## 三、功能模块总览

系统共 9 个功能页面 + 3 个核心组件：

**学习主线**
- 📖 **章节学习**（第十一章 IS-LM 模型）：按小节组织知识点，含公式推导分步展示、符号说明表、知识图示（ECharts）
- 🔬 **交互仿真实验**：IS-LM 仿真器支持参数调节、政策冲击模拟、对比模式，可从知识点和习题两处一键唤起
- 📝 **课后习题**：8 道题（单选 + 计算题），提交后自动判分、展示解析，计算题可用仿真器复现验证

**AI 智能导学（本次新增，核心亮点）**
- 🎓 **阶梯导学面板**：每道题下方内嵌，逐级提示 + 困惑重试 + 完整解析 + 反馈收集

**学习管理**
- 错题本、课程表、资源库、学习统计、AI 助手、社区讨论

## 四、核心亮点：基于 RAG 与 CoT 的阶梯导学

### 4.1 设计理念

学生卡壳时，系统**不直接给答案**，而是像老师一样分四层引导：

| 层级 | 内容 | 是否含答案 |
|---|---|---|
| L1 | 宏观思考方向（"先定分析框架"） | ❌ |
| L2 | 关键条件 + 对应知识点（RAG 检索命中的知识卡） | ❌ |
| L3 | 思路框架分步列出，**最后一步留白 ❓ 让学生自己完成** | ❌ |
| L4 | 完整解析（答案 + 过程 + 经济学含义 + 易错点） | ✅ 需弹窗二次确认，且记录行为日志 |

层级**单调递增不可回退**，防止反复刷提示；困惑重试（学生描述"我卡在哪"）按当前层级重新检索生成，**不越级**。

### 4.2 防直接抄答案的三道防线

这是本功能区别于"直接问大模型"的关键：

1. **RAG 知识库过滤**：L1~L3 检索时自动剔除含答案数值的知识块，L4 才全量放开——答案根本不进入模型上下文；
2. **输出泄露校验**：模型每次输出都要过"数值/选项字母检测"，一旦发现疑似泄露答案，自动追加严厉提醒重试一次；
3. **降级兜底**：重试仍不合格则降级为直出知识库原文（知识卡模式），绝不静默失败、也绝不泄露答案。

> 该链路已实测触发：一次输出携带答案数值 1266.67，被拦截 → 重试 → 仍不合格 → 自动降级直出知识卡，全程无答案外泄。

### 4.3 与大模型的结合方式

- 大模型采用**豆包**（火山方舟 Ark，doubao-1-5-pro-32k，OpenAI 兼容协议）；
- **System Prompt** 约束角色为"导学老师"，铁律：L1~L3 严禁出现最终答案数值/选项字母，只输出规定格式的 JSON；
- **User Prompt** 动态注入：题干、学生作答快照、判分结果、已解锁层级、RAG 检索命中的知识块、学生困惑文本——提示随学生状态个性化；
- **CoT 思维链**在模型内部逐步推理，但外部只输出当前层级内容，避免一次性泄露全部思路；
- 未配置 API Key 时自动切换**本地模拟模式**，保证开发调试不依赖外部服务。

### 4.4 会话状态与数据落库（MySQL）

| 表 | 作用 | 关键字段 |
|---|---|---|
| `hint_session` | 每生每题一条会话 | `current_level`（单调递增）、`solution_unlocked`、`rag_snapshot`（检索快照复用）、`attempt_count` |
| `hint_log` | 每次提示一条日志 | `level`、`trigger_type`（逐级/困惑/直出解析）、`content`（JSON）、`prompt/completion_tokens`、`degraded`（是否降级） |

日志落库带来两个能力：**刷新页面后历史提示卡片自动恢复**；反馈数据（有帮助/没帮助）可用于后续学习行为分析。

## 五、技术架构

```
浏览器（Vue 3 + Element Plus + ECharts + Vite）
   │  HintPanel 提示面板 / ISLMSimulator 仿真器
   │  /api 代理（Vite dev proxy，同源无 CORS）
   ▼
后端（Node.js + Express 5）
   │  路由层：参数校验、统一错误包裹（不外泄堆栈/答案）
   │  服务层：hintService 编排（会话→RAG→提示词→LLM→校验→落库）
   │  RAG：知识块分块 + 关键词检索；leakGuard：泄露检测
   ├──────────────► MySQL 8.4（hint_session / hint_log）
   └──────────────► 豆包大模型（火山方舟 Ark API，可 MOCK）
```

- 前后端分离，接口统一 `{ success, code, message, data }` 信封格式；
- 错误处理分级：业务错误（如 `LEVEL_LOCKED` 渐进提示到顶）与系统错误分离，绝不把答案内容当作错误信息返回前端；
- 配置集中在 `.env`（端口/数据库/大模型），代码零硬编码。

## 七、现场演示动线（约 5 分钟）

1. **打开系统** → 第 11 章 → 知识点小节：展示公式推导、符号表、知识图示（30 秒）
2. **打开交互仿真实验**：调一个政府支出参数，现场看 IS 曲线右移、均衡产出与利率变化（1 分钟）
3. **课后习题**：故意做错一道计算题（错误提交）→ 下方导学面板点「获取提示」×3，展示 L1 方向 → L2 知识卡 → L3 留白框架（2 分钟）
4. **困惑重试**：在困惑框输入"我不知道 r 怎么代入"，展示个性化重新提示（30 秒）
5. **查看完整解析**：二次确认弹窗 → L4 展示答案 + 过程 + 易错点；**刷新页面**展示历史卡片恢复（1 分钟）

## 八、老师可能提问 & 回答要点

**Q：为什么不直接让学生问大模型？**
A：三个原因——通用对话会直接给答案，破坏训练价值；模型可能编造教材外内容（幻觉），我们用 RAG 限定在第 11 章知识库；通用模型无学习行为记录，无法做后续教学分析。

**Q：RAG 为什么用关键词匹配而不是向量检索？**
A：当前知识库规模小（单章内容分块），关键词匹配已够用且零外部依赖、结果可解释；架构上检索器是独立模块，后续可平滑替换为向量检索。

**Q：如何保证模型不泄露答案？**
A：纵深防御——检索端先过滤（答案不进上下文），输出端再校验（数值/选项检测），重试一次后仍失败则降级为知识卡直出。已实测触发过降级链路。

**Q：大模型接的是哪家？成本如何？**
A：豆包（火山方舟），OpenAI 兼容接口，单次调用带 25s 超时与失败重试；每次调用的 token 用量已落库，便于统计成本。开发期用本地模拟模式，零成本。

**Q：后续计划？**
A：① 反馈数据驱动的提示质量迭代；② 扩展到更多章节（知识分块与习题配置是数据驱动的，新增章节只需加数据文件）；③ 检索升级向量版；④ 老师端查看学生卡点分布。
