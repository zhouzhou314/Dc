# 《大创创新点说明》—— IS-LM 曲线交互式仿真实验平台

> 面向大学生创新创业训练计划申报书与答辩材料。本文档按模块归纳创新点、整体技术架构、与同类平台的对比，以及现场答辩演示脚本。

---

## 一、项目定位

**基于"AI 阶梯导学 + 学习分析 + 交互仿真"的宏观经济学（IS-LM 模型）智能学习平台。**

面向宏观经济学的三个教学痛点：

| 痛点 | 传统做法 | 本平台方案 |
|---|---|---|
| 学生"卡壳"只能问老师/同学 | 直接给答案，破坏思考过程 | L1→L4 阶梯式 AI 导学，先方向、后公式、再框架，最后才给完整解析 |
| 老师不知道学生哪里薄弱 | 靠批改作业，反馈滞后 | 贝叶斯知识追踪（BKT）实时估计知识点掌握概率，自适应推荐练习 |
| 抽象模型"看不见摸不着" | 黑板画静态图 | 参数可调的 IS-LM 双曲线交互仿真，AI 智能体可调用求解器实时答疑 |

## 三、分模块创新点

### 创新点 1：AI 阶梯导学与"防泄露"工程（AI 增强）

**做了什么**：把每道题的提示拆成 L1 方向 → L2 关键公式/概念 → L3 思路框架（含留白）→ L4 完整解析四个层级，由大模型按层级生成；学生必须逐级解锁，系统全程记录行为数据。

**技术上新在哪里**：

1. **答案根本不进模型上下文**：L1~L3 的提示词中官方答案字段恒为"（按规则隐藏）"，从源头杜绝模型"顺嘴"报答案——比常见的"生成后过滤"更彻底。
2. **三级泄露防护链**：输出校验（正则扫描答案数值/选项字母）→ 追加严厉提醒重试 1 次 → 仍不合格则降级为知识卡直出。链路可用 `MOCK_LEAK=true` 一键复现（答辩亮点：证明安全设计经过可复现实验验证）。
3. **先定稿后回放的流式方案**：泄露校验必须针对完整文本进行，因此采用"完整生成 + 校验 → SSE 分段回放"架构，兼顾打字机体验与 100% 安全审查——这是对"流式输出无法中途审查"矛盾的工程化解法。

### 创新点 2：Function Calling 教学智能体（AI 增强）

**做了什么**：AI 助手不只是聊天，而是一个会"动手"的智能体：自主决定调用三个工具——IS-LM 求解器（缺参自动补默认值）、课程知识库检索（混合 RAG）、题库查询（只回题干摘要、绝不含答案），工具循环上限 4 轮防失控。

**技术上新在哪里**：

1. **工具调用过程全可视化**：前端以步骤条实时展示"正在调用 IS-LM 求解器…"→ 执行结果摘要，把黑盒 AI 变成可解释的"过程演示"——教学场景下比纯聊天更有说服力。
2. **混合检索 RAG**：领域词典分词 + 简化 TF-IDF 关键词召回 × 向量余弦语义召回，加权融合排序；无向量时自动退化为纯关键词，鲁棒性强。
3. **双模式确定性 Mock**：无 API Key 时智能体走本地关键词路由器，工具调用、流式输出、步骤条全链路可演示——保证答辩现场不依赖网络与密钥（红线设计）。

### 创新点 3：BKT 贝叶斯知识追踪 + 自适应推荐（学习分析）

**做了什么**：学生每次作答都上报，后端用 BKT 模型在线更新每个知识点的掌握概率 P(L)，并据此自适应推荐练习题。

**技术上新在哪里**：

1. **认知科学模型而非正确率统计**：采用经典 BKT 四参数（先验 P(L0)=0.15、学习转移 T=0.10、猜测率 G=0.20、失误率 S=0.10），由作答序列反推"真实掌握概率"——答对一次≠掌握，BKT 能表达"猜对"与"失误"，比正确率更接近真实学情。
2. **推荐三因子**：最薄弱知识点优先 × 难度阶梯爬升 × 做得少的知识点优先，形成"哪里不会练哪里"的闭环。
3. **SM-2 间隔重复**：错题本内置 SuperMemo-2 算法（EF' = EF + (0.1 − (5−q)(0.08 + (5−q)·0.02))），按"记得/模糊/忘了"三键评分自动排期复习（1 天 → 6 天 → EF×前值），把记忆科学写进工程。

### 创新点 4：匿名/登录双模式与零破坏工程（平台工程）

**做了什么**：JWT + bcrypt 完整用户体系，但匿名用户无需注册即可使用全部功能；登录后错题本自动云同步（多端一致），且合并策略为"云端复习次数大者胜"。

**技术上新在哪里**：

1. **可选认证中间件**：有 Bearer 解析身份、无 token 匿名放行，所有云端写入均 fire-and-forget（失败静默），同步故障绝不阻塞学习主流程。
2. **三重降级链**：真实豆包 → 本地 Mock；向量检索 → 纯 TF-IDF；后端计算 → 前端本地求解。**关掉后端，前端依然可玩**——答辩时可现场演示"拔线不崩"。

### 创新点 5：一键容器化部署（平台工程）

- 多阶段 Dockerfile（node:20-alpine，构建/运行分离，镜像精简）；
- docker-compose 内置 MySQL 健康检查 + 应用启动重试（5×3s），解决容器编排里"应用比数据库先起"的经典竞态；
- named volume 数据持久化，`down && up` 数据不丢。

| 能力 | 智能题库类 App | MOOC 平台 | 通用 ChatBot 辅导 | **本平台** |

## 五、答辩演示脚本（约 6 分钟）

1. **首页 → 仿真验证**（1 min）：调节 G 与 M/P 演示财政/货币政策下 IS/LM 曲线移动与均衡点迁移；打开对比仿真看"挤出效应"。
2. **题库练习 → 阶梯导学**（2 min）：选一道计算题，逐级点 L1→L3（打字机流式效果），填入困惑文本演示"按我的困惑重新提示"；最后查看完整解析。
3. **AI 助手 → 智能体对话**（1.5 min）：输入"帮我求解 IS-LM 均衡"，现场看 Function Calling 步骤条（求解器 → 结果）+ 流式回答；再问"推荐几道练习题"看题库工具。
4. **学情统计 + 复习模式**（1 min）：雷达图看 BKT 掌握度；错题本点"复习模式"，按"记得/模糊/忘了"评分演示 SM-2 排期变化。
5. **鲁棒性彩蛋**（0.5 min）：现场停掉后端进程，刷新页面——仿真、练习、本地功能照常可用（三重降级红线）。

## 六、技术栈清单

- **前端**：Vue 3.5（Composition API）、Vite 5、Element Plus、ECharts 5、原生 fetch/ReadableStream（SSE）
- **后端**：Node.js 20、Express 5、MySQL 8（mysql2 连接池）、jsonwebtoken、bcryptjs
- **AI**：豆包大模型（火山方舟 Ark OpenAI 兼容协议）、Function Calling、SSE 流式、混合 RAG（TF-IDF × 向量余弦）
- **算法**：BKT 贝叶斯知识追踪、SM-2 间隔重复、自适应三因子推荐
- **部署**：Docker 多阶段构建、docker-compose（healthcheck + 重试 + 数据卷）
