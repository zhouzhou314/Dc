# IS-LM 平台大创升级实施计划（AI 增强 + 学习分析 + 平台工程）

## Context（背景）

项目现为 Vue3 + Vite + Element Plus + ECharts 前端、Express 5 + MySQL + 豆包 LLM 后端的 IS-LM 宏观经济学教学平台，已有阶梯导学（L1-L4 提示、泄露校验、TF-IDF 检索、MySQL 会话）。但错题本/统计仅存 localStorage、AI 助手页无真实对话、检索是关键词级、无用户体系、无可流式输出。

用户（大创项目负责人）要求加入"高端技术"以支撑大创申报与答辩，已确认三大升级包全做，并需生成《大创创新点说明》文档。**红线约束：所有新 AI 能力必须有 mock 兜底（无 ARK_API_KEY 全流程可演示），匿名用户体验零破坏。**

## 新装依赖（仅 2 个）

```
jsonwebtoken@^9.0.2   # JWT 签发/校验
bcryptjs@^2.4.3       # 密码哈希（纯 JS，Windows 无编译问题）
```

SSE 前后端用原生 fetch/ReadableStream，零新增前端依赖。

## 实施阶段

- `server/middleware/auth.js`（新）：可选认证中间件——有 Bearer 解出 req.user，无 token 匿名放行；提供 `resolveUserId(req)`（登录用户 `u_<id>`，匿名用 hintUserId）
- `server/services/userService.js`（新）：bcryptjs 哈希、jsonwebtoken 签发
- `server/routes/auth.js`（新）：POST /api/auth/register（重复 409 USER_EXISTS）、POST /api/auth/login（密码错 401）、GET /api/auth/me
- `server/app.js`：挂载 /api/auth

**前端**
- `src/store/auth.js`（新）：token/用户存 localStorage（key: islm_auth），isLoggedIn/user/token + login/logout
- `src/api/auth.js`（新）：register/login/me 封装
- `src/views/LoginView.vue`（新）：Element Plus 登录/注册表单，成功回首页
- `src/App.vue`：currentView 加 'login' 分支（沿用手动切换，不引 vue-router）；首页加登录入口、已登录显示昵称
- `src/store/learning.js`：addWrong/removeWrong/setWrongReason 内加 `if (authStore.isLoggedIn)` fire-and-forget 云同步（失败静默不阻塞）

**检查点**：注册/登录/刷新保持登录态；匿名模式所有旧功能零变化；curl 验证 409/401 分支。

### 阶段二：学习分析包（BKT + 自适应推荐 + SM-2）

**后端**
- `server/services/bktService.js`（新）：BKT 贝叶斯知识追踪，参数定死常量 P(L0)=0.15 / T=0.10 / G=0.20 / S=0.10（注释解释含义）；每次作答后更新 mastery_state
- `server/routes/record.js`（新）：POST /api/record/answer（落 answer_record + 触发 BKT，返回更新后 mastery）
- `server/services/recommendService.js`（新）：最薄弱知识点 + 难度阶梯 + 少做优先，从 questionBank 选题；只回题 id + 推荐理由（题库本来就在前端，不新增泄露面）
- `server/routes/analytics.js`（新）：GET /api/analytics/mastery（各 topic pKnown，无记录返先验 0.15）、GET /api/analytics/recommend
- `server/services/reviewService.js`（新）：SM-2 算法，`EF' = EF + (0.1 - (5-q)*(0.08 + (5-q)*0.02))`，q<1 重置；interval 序列 1→6→EF×前值
- `server/routes/wrongbook.js`（新）：list/add(UPSERT, times+1 且重置 SM-2)/remove/reason
- `server/routes/review.js`（新）：GET /api/review/due（due_date<=今天，上限 20）、POST /api/review/grade（remember→q5 / fuzzy→q3 / forgot→q1）

**前端**
- `src/api/record.js`、`src/api/review.js`（新）：接口封装
- `src/views/ExerciseView.vue`：submit()（L307 附近）判定后 fire-and-forget 上报 /api/record/answer；setup 面板加"智能推荐练习"按钮，拉 recommend 回填 sessionQuestions
- `src/views/StatsView.vue`：雷达图优先用 GET /api/analytics/mastery（pKnown×100），接口不可用回落 store.mastery
- `src/views/WrongBookView.vue`：加"复习模式"（到期队列 + 记得/模糊/忘了三键评分）；登录用户增删改同时调云接口，登录时拉取合并（合并策略：云端 times 大者胜）

**检查点**：重复答对 pKnown 上升、答错下降；推荐题来自最弱 topic；错题进复习队列、评"记得" due 后移；换浏览器登录错题一致。

### 阶段三：AI 增强包（SSE 流式 + 向量 RAG + Function Calling）

**流式**
- `server/services/llm.js`：加 `chatLLMStream()`——真模式 Ark `stream:true` 用 fetch 解析 `data:` 行；mock 模式把 mock 文本切段、40ms 延时 yield。现有 chatLLM 不动
- `server/routes/hint.js`：加 POST /api/hint/stream——**先完整跑现有 getHint() 管线（泄露校验/重试/降级不破坏）**，再 SSE 回放：meta → delta*(30-40字/段, ~40ms) → done；HintPanel SSE 异常时回落旧 POST /api/hint
- `src/api/sse.js`（新）：fetch + ReadableStream 的 SSE 读取器（EventSource 不支持 POST）
- `src/components/HintPanel.vue`：新提示走 /api/hint/stream 打字机气泡，done 后替换为结构化卡片，失败回落

**向量 RAG**
- `server/services/embeddingService.js`（新）：真模式调 Ark /embeddings（doubao-embedding 系列）批量向量化知识块存 knowledge_embedding；mock 模式确定性伪向量（字符 bigram 哈希 256 维 + L2 归一化，同输入恒同输出）；启动时向量表为空自动构建；余弦计算
- `server/services/retriever.js`：retrieve() 混合打分 `score = 0.5*tfidf_norm + 0.5*cosine`，无向量自动退化纯 TF-IDF
- `server/routes/embedding.js`（或并入 analytics）：POST /api/admin/embeddings/rebuild

**Function Calling 智能体**
- `server/services/islmSolver.js`（新）：islmCalc.js 纯数学部分移植后端
- `server/routes/islm.js`（新）：POST /api/islm/simulate、/api/islm/compare（补齐 src/api/islm.js 注释里的正式接口；非法参数 400）
- `src/api/islm.js`：改为"先真请求，异常回落本地 calcIslmCurves"
- `server/services/agentService.js`（新）：工具循环（最多 4 轮）；工具 3 个：islm_solve（缺参用 presets.js 默认值补齐）/ knowledge_search（调 retriever）/ question_query（查 questionBank 返回不含答案的摘要）；真模式 tools+tool_calls，mock 模式关键词路由（"求解/均衡/Y*"→islm_solve、"题/练习"→question_query、其余→knowledge_search）
- `server/prompts/agent-system.txt`（新）：智能体系统提示词（教学口吻、不直接报答案数值）
- `server/routes/agent.js`（新）：POST /api/agent/chat（SSE：tool_call → tool_result → delta* → done / error）
- `src/api/agent.js`（新）：SSE 调用封装，回调 onToolCall/onToolResult/onDelta/onDone
- `src/views/AiAssistantView.vue`："自由提问"改真实对话：消息列表 + 流式打字气泡 + 工具调用步骤条（"正在调用 IS-LM 求解器…"）；保留原有 Tab

**检查点**：LLM_MOCK=true 下 AI 助手可对话、可见工具调用步骤、流式逐字输出；MOCK_LEAK=true 复测泄露降级链路不变；检索 score 为混合分；关掉后端前端仍可玩。

## 风险与规避

1. SSE × Vite 代理：服务端 `res.flushHeaders()` + `X-Accel-Buffering: no` 头 + 15s `: ping` 心跳；HintPanel 必须保留旧接口兜底
2. mock 一致性（红线）：三条 AI 能力各自确定性 mock，全部复用 LLM_MOCK 开关，不新增"半真半假"组合
3. init.sql 分号陷阱：新 DDL 注释禁用半角分号（db.js L38-40 按 `;` 切分）
4. 双模式数据冲突：云上报全部 fire-and-forget；登录合并"云端 times 大者胜"
5. Ark embedding 端点：实现时先小脚本验证 /embeddings 可用，不可用走伪向量不影响交付
